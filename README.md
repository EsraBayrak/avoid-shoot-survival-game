# Avoid & Shoot Survival Game

A 2D survival shooting game developed using HTML5 Canvas and JavaScript for the Computer Graphics course project.

## 🎮 Game Features
- WASD / Arrow Keys movement
- Shooting mechanics
- Increasing difficulty system
- Boss enemies
- Health pack system
- Particle explosion effects
- Screen shake effect
- Collision detection
- Best score saving system

## 🕹️ Controls
- Move: WASD or Arrow Keys
- Shoot: Space

## 🚀 Technologies Used
- HTML5 Canvas
- JavaScript
- CSS
